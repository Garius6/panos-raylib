# raylib для panos

Библиотека-обёртка над [raylib](https://www.raylib.com/) для языка
[panos](https://github.com/Garius6/panos), написанная поверх настоящего
динамического FFI (`внешний`/`ff_структура`, Стадии 47-51) — panos core
ничего не знает про raylib, это обычная `.ps`-библиотека, как любая
другая.

## Требования

- Установленный raylib: `brew install raylib` (macOS).
- **Единственная проверенная платформа — macOS/Apple Silicon.** Путь к
  библиотеке захардкожен в `raylib.ps`
  (`/opt/homebrew/opt/raylib/lib/libraylib.dylib`) — честно
  задокументированный пробел, не скрытый. На Intel-Mac/Linux путь нужно
  поправить вручную (см. "Известные ограничения" ниже).
- panos с поддержкой `внешний`/`ff_структура` (Стадия 51+).

## Установка

panos пока не имеет пакетного менеджера ([`pan`](https://github.com/Garius6/panosiki)
в разработке) — библиотека распространяется как обычный файл. Скопируйте
`raylib.ps` в директорию своего проекта (рядом с исходником, который его
импортирует, или в поддиректорию `модули/`):

```
$ cp raylib.ps путь/к/вашему/проекту/
```

## Использование

```panos
импорт raylib

функ старт() -> Пусто
    raylib.инициализировать_окно(800, 450, "моё окно")
    raylib.задать_fps(60)

    пока raylib.окно_должно_закрыться() == ложь цикл
        raylib.начать_рисование()
        raylib.очистить_фон(raylib.Color(20, 20, 20, 255))
        raylib.нарисовать_прямоугольник(raylib.Vector2(100.0, 100.0), raylib.Vector2(50.0, 30.0), raylib.Color(255, 0, 0, 255))
        raylib.нарисовать_круг(raylib.Vector2(300.0, 200.0), 25.0, raylib.Color(0, 255, 0, 255))
        raylib.закончить_рисование()
    конец

    raylib.закрыть_окно()
конец
```

Полный рабочий пример — [`pong.ps`](./pong.ps): классический pong, весло
игрока (стрелки вверх/вниз), простой ИИ-соперник, счёт печатается в
консоль при пропущенном мяче.

```
$ ./panos pong.ps
```

## API

### Окно и цикл отрисовки

- `инициализировать_окно(ширина: Целое, высота: Целое, заголовок: Строка) -> Пусто`
- `окно_должно_закрыться() -> Булево` — `истина`, когда пользователь
  закрыл окно (крестик/Esc).
- `закрыть_окно() -> Пусто`
- `начать_рисование()` / `закончить_рисование()` — окружают каждый кадр,
  всё рисование (`нарисовать_*`) действует только между ними.
- `задать_fps(fps: Целое) -> Пусто`
- `время_кадра() -> Число` — секунды с прошлого кадра (`dt`), для
  движения, не зависящего от FPS.

### Рисование

- `очистить_фон(цвет: Color) -> Пусто`
- `нарисовать_прямоугольник(позиция: Vector2, размер: Vector2, цвет: Color) -> Пусто`
- `нарисовать_круг(центр: Vector2, радиус: Число, цвет: Color) -> Пусто`

### Типы

- `Vector2(x: Число, y: Число)` — `ff_структура`, два `f32`-поля (C ABI
  raylib'овского `Vector2`).
- `Color(r: Целое, g: Целое, b: Целое, a: Целое)` — `ff_структура`,
  четыре беззнаковых байта (0..255), C ABI raylib'овского `Color`.

### Ввод

- `клавиша_нажата(клавиша: Целое) -> Булево`
- `клавиша_вверх()` / `клавиша_вниз()` / `клавиша_влево()` /
  `клавиша_вправо()` / `клавиша_пробел()` / `клавиша_escape()` — коды
  клавиш raylib (`KeyboardKey`), геттеры вместо символьных констант (у
  panos пока нет механизма импорта чужих enum'ов).

## Известные ограничения

- **Путь к библиотеке захардкожен.** `внешний`-декларации требуют полный
  путь для библиотек не на стандартных путях поиска dyld/ld.so (raylib —
  не системная библиотека вроде libc). Если raylib установлен не через
  `brew install raylib` на Apple Silicon — поправьте путь в начале
  `raylib.ps` (12 строк `внешний "..." функ ...`) под свою систему,
  например `/usr/local/lib/libraylib.so` на Linux.
- **Только плоские структуры.** `ff_структура` не поддерживает вложенные
  структуры/строки/указатели как поля — этого достаточно для `Vector2`/
  `Color`, но не для более сложных raylib-типов (`Texture`, `Font` и
  т.п.) — они пока не обёрнуты.
- **Графический цикл голодит другие panos-процессы.** planos-планировщик
  кооперативный, без преемптивности — синхронный `raylib.*`-вызов внутри
  `пока raylib.окно_должно_закрыться() == ложь цикл ... конец` не
  уступает управление другим `запусти`-процессам, пока окно не закроется.
  `pong.ps` этого не показывает (не использует процессы).

## Лицензия

Код распространяется как есть, без отдельной лицензии — то же условие,
